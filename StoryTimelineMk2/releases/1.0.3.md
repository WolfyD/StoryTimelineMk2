<!-- 1.0.3 - small updates. One bullet per user-visible change, grouped by ## area. -->

## Filters

- Filter rules can now be deleted: open the filter setup (gear) and click the red X on a chip. With the setup closed, the X still just deactivates an active filter. Saved presets are unaffected.

## Everywhere

- Number fields (years, days, settings values…) now step with the mouse wheel while focused, and the page no longer scrolls behind them. Up/Down arrow keys step them too.

## Edit item window

- The X in the window's title bar now asks "Discard changes?" when there are unsaved edits, like Cancel and Escape do.
- The Description box is taller (about seven lines instead of two).
- New **Side** toggle next to Importance: put an item above or below the timeline, or leave it on Auto and let the app pick the emptier side.
- New **Centered** checkbox for events and notes: the box sits centered on its stem instead of off to one side.
- New **Show title** checkbox for pictures: draws the title as a caption strip along the bottom of the image on the timeline.
- The timeline's most-used tags appear under the tag box as "+ tag" chips — click one to add it. Tags already on the item are not offered.
- New collapsed **Item Notes** section below Images: private bookkeeping that is saved, exported and copied with the item but never shown on the timeline, in the data panel or in the item popup.
- Tidier Details layout: Importance and Show in notes share a row; Side, Centered and Show title have their own row.
- Closing the edit window after switching to another program and back no longer brings that other program to the front — the timeline window gets the focus.

## Timeline window

- The title header above the timeline can now be made compact (a single small title line) or hidden entirely: Timeline settings → Window → Title Header. The window's title bar still shows the title.
- Shift+click an item to open it straight in the edit window, skipping the view popup.
- The 12 quick-pick colours in the edit item window are now yours to choose: Timeline settings → General → Colour Swatches shows the current set as a row of dots; click it to edit the colours, with a Reset to defaults button. Each timeline keeps its own set.
- Choose which zoom levels new items are visible at by default: Timeline settings → General → New Items Visible At shows the current choice ("All levels", "Years, Months"…); click it to tick the levels by their full names. Existing items are untouched; each new item can still be changed in its edit window.
- Actions menu (⋮) → **Set Visibility Of All Items**: a **Set visibility…** button opens a dialog listing the zoom levels by name; tick the ones you want and press **Apply to N items** to replace every item's own setting at once. Nothing changes until that button is pressed, so the menu itself can't alter your items by accident.
- New **Mass add items** button on the activity strip (below Tags): type a title, pick a type from the Event / Period / Age / Note toggle and a year (Periods and Ages get a To year that starts one after From), press Add, repeat. The type and — with **Remember year** on, which it is by default — the year stick between adds; nudge the year with the − / + buttons or with Shift + / Shift − from anywhere in the window, even while typing the title. From and To may be entered in either order; equal years give a one-year range. Click a queued row to edit it (Add becomes Update), remove what you don't want, then press **Finished** to save them all. Items get the timeline's default colour and visibility, and can be fleshed out in the edit window later.
- Confirmation questions (discard unsaved items, discard edit-window changes) now use the app's own dialog instead of the browser's plain popup.
- If the timeline window's page has crashed (a black window), closing it no longer throws an "CoreWebView2 members cannot be accessed" error and leaves the window stuck — it closes and, since the main window's page is gone too, the app exits cleanly.

## Data panel

- Descriptions and content keep their line breaks and indentation instead of collapsing into one paragraph.

## Calendars

- The collapsed Memorable Days section in the calendar editor now shows how many entries it holds.
- Memorable days have their own editor: the section lists the days as coloured chips and a **Manage days…** button opens a window with the list on the left and the selected day's colour, name, type and date picker on the right. Click a chip to jump straight to that day. Changes apply as you make them; Save on the calendar stores them as before.
- Removing a level from a calendar's LOD profile now sticks: reopening the calendar no longer brings it back.
- When the calendar editor adds a level automatically (for example after enabling seasons), it goes in the right place in the list instead of at the end.
- Calendars can now be shared as files. In the calendar manager each row has an **Export** button and the footer has **Import Calendar**; the calendar editor's header has **Export** too, which writes what is on screen even before you save. A file holds the calendar's names, months, weeks, seasons, memorable days and LOD profile. Importing always creates a new calendar and never touches existing ones; if a calendar with the same name already exists you are told so you can rename one.
