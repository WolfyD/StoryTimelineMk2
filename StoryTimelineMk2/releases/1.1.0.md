## Pictures

- WebP images now get proper thumbnails like every other format, so galleries and picture lists load
  faster and look consistent. Previously WebP fell back to the full-size file.

## Backup and export

- **Export Database can now take your pictures with it.** It asks first: leave the box unticked and
  you get the database file on its own, as before; tick it and you get a `.stlm` archive holding the
  database and every picture. Until now only a manual backup could do that, so an export moved to
  another computer arrived with empty picture frames.
- **Import Database reads those archives back**, pictures and all, so a database and its images can
  travel together in one file. Anything already in your pictures folder is left untouched — an
  import only fills in what is missing.
- Exports and backups are now taken as a proper snapshot of the database rather than a copy of the
  file on disk, so the very newest changes can no longer be left out of one.

## Sharing your work

- **Export is now a button on the timeline itself**, just above the `?`, so you no longer have to
  go back to the project list to find it.
- **You can hand someone just the part you wrote.** The export dialog has a second tab, *My work*,
  which lists every day you spent on this timeline and what you did on each. Tick the days you want
  to send and they go as one small `.stlc` file. Your co-writer imports it into their copy with
  **Import Changes** in the database menu, and only those edits move across — the rest of their
  timeline is untouched.
- **It remembers where you got to.** One button picks everything since your last export, so you
  never have to work out what you already sent. If you would rather choose by date there are two
  date boxes that clamp the list, and you can untick any day inside it — useful when last
  fortnight is finished but this week is not. An item you worked on across several of the chosen
  days travels once, as you last left it, and something you started and scrapped inside that
  stretch is not mentioned at all.
- **If you both edited the same thing, you get to choose.** The import screen puts the two versions
  side by side, highlights what differs, and lets you keep yours or take theirs for each item, with
  buttons to decide all of them at once. Left alone, the incoming version wins.
- Your work is now tallied per day and kept, so closing the app no longer loses track of what you
  changed. Come back next week and last Tuesday is still on the list, waiting to be sent.

## Getting around the timeline

- **On-screen scroll buttons**, off by default — turn them on in App settings → Appearance. You get
  a round button on each side of the timeline that scrolls it for as long as you hold it down, the
  same thing the ← / → keys do, for when your hand is already on the mouse. Hold Shift while you
  hold a button for triple speed.
- **The scroll speed is now a box at the bottom of the timeline window**, next to the FPS counter,
  so you can tune it while you are actually scrolling instead of opening Timeline settings for it.
  It is the same setting, so changing it in either place changes it in both.
- **Shortcuts are now written the Mac way on a Mac** — ⌘, ⌥ and ⇧ rather than Ctrl, Alt and
  Shift — everywhere they are shown: the shortcuts list, Help, and the hints on buttons and text
  boxes. The keys themselves always worked; only the labels were wrong. The shortcuts list also
  explains what macOS does with the F-keys and how to get them back.
- **Holding Ctrl while you turn the wheel now only zooms.** It was zooming *and* scrolling the
  timeline along, or nudging whatever number box you had clicked into, so one turn of the wheel did
  two things at once. A pinch on a Mac trackpad had the same problem, since a Mac sends one as
  Ctrl+wheel.

## Keyboard and modals

- **Every dialog now answers Enter and Esc.** Enter does the main thing — Save, Import, Select —
  and Esc backs out, with a small hint printed on the buttons themselves so you can see which is
  which. Inside a multi-line text box Enter still starts a new line; hold Ctrl and it confirms.
  The edit window is the exception, on purpose: there Ctrl+S saves and Enter stays out of the way.
- **Selecting text in a dialog no longer closes it.** If you dragged from inside a dialog and let
  go of the mouse outside it, the dialog took that as a click on the background and shut. It now
  only closes when the press *starts* on the background.
- A few dialogs — the theme picker, the year view and the image picker — never listened for Esc
  at all. They do now.
- **You can change the keyboard shortcuts.** Press F2 for the shortcuts list, click
  **Customise…**, then click any shortcut and press the keys you want. Backspace puts one back to
  its default, Esc cancels, and **Reset all** puts everything back. The list warns you if the
  combination is already taken, and it refuses the handful the app cannot work without — Esc,
  Enter, Tab, F1 and F2 — along with the arrow keys, Ctrl+S and Ctrl+Z, which stay as they are.
  Your choices are remembered and apply straight away, including the letters in the new-item type
  picker.

## Performance

- **Low resource mode** — a new switch in App settings → Performance, off by default. It trades
  some polish for speed on a busy timeline: the view jumps straight to where it is going instead
  of gliding there, changing detail level is instant, the marker that follows your cursor is
  switched off, the minimap is hidden, and the canvas is drawn at 1:1 rather than at your
  display's full pixel density — sharp text costs four times the drawing on a high-resolution
  screen. Items are drawn more simply too: their colour shows on the box border instead of a
  separate stripe, and hovering one makes it grow a little rather than glow. Reopen the timeline
  window for it to take effect; the FPS counter at the bottom of the window will tell you whether
  it helped.

## Help

- **Help has caught up with the app.** Press F1 for a run-through of every button in the strip
  across the top of the timeline, the new on-screen scroll buttons and speed box, sharing work with
  a co-writer (including what *Incoming* and *Local* mean on the import screen), what Enter and Esc
  do in any dialog, how to change a shortcut, and what Low resource mode actually switches off.
- **About now links to the source code** for the exact version you are running, rather than leaving
  you to find the right one. Story Timeline is free software under the AGPL, which asks that anyone
  using it — including over a browser — can get at the code behind it.

## Under the hood

- The part of Story Timeline that stores your data no longer depends on Windows. Nothing changes for
  you on Windows; it is the first step toward running Story Timeline on macOS and Linux.
- Story Timeline can now run in an ordinary web browser, served by a small program on your own
  machine — the groundwork for the macOS and Linux versions. Every screen works there, not just the
  read-only ones: the timeline, the edit window and the calendars open in their own browser windows,
  Import opens the usual file picker, Export downloads the file, and full screen, fonts and Help
  links all behave. Nothing leaves your computer — the program only answers your own machine, never
  the network. Nothing changes on Windows, where the app runs as it always has.
- The browser version now closes properly: pressing Ctrl+C in its window stopped it only after
  a 30-second wait if you still had a page open, which looked like the key did nothing. It stops
  straight away now.
- In the browser version the window title bar no longer pretends to be a window: the pin,
  minimise and maximise buttons are gone, since the browser already has those, and in their place
  a timeline opened from the project list gets a **Back** button to return to the list. Pop-out
  windows keep a close button.
- Browser tabs are now labelled with what is in them — the timeline's name, the item you are
  editing, the calendar you have open — instead of all reading the same thing.
- In the browser version, closing the edit window with unsaved work now asks first. Its X already
  did, but closing the tab itself, Ctrl+W (⌘W) or the Back button threw the item away without a
  word.
- The browser version now says **Finder** on a Mac and *your file manager* on Linux, on the buttons
  that open your data and backup folders and in the message that hands you the path. All three used
  to say Explorer.
- Font pickers in the browser version now fall back to fonts the machine actually has. On a Mac the
  list offered Segoe UI and Calibri, which no Mac ships; Macs and Linux each get their own list now.
  If you let the browser read your installed fonts, that still takes precedence, as before.
- The download list now includes this browser version for Windows, Linux and both kinds of Mac
  (Apple Silicon and Intel). Each one is a single self-contained download with nothing to install
  first: start it, then open the address it prints. The Mac and Linux ones arrive as `.tar.gz`
  files, and on a Mac you have to clear Apple's download quarantine once before it will start —
  `xattr -dr com.apple.quarantine StoryTimeline.Server`. Each download now comes with a **Start
  Story Timeline** shortcut sitting next to the program, so you can double-click that instead of
  typing a command; you still open the address it prints yourself.
