## Calendars

- Calendars can be deleted from the calendar manager. Timelines that used the deleted calendar switch to the default Gregorian calendar — the confirmation says how many are affected. The default calendar itself cannot be deleted.
- Each calendar shows how many timelines use it.
- Calendar lists refresh on their own when the calendar editor closes.

## Items

- New items keep the side of the line (above / below) they were first placed on instead of shuffling when other items are added or removed. The side is chosen to balance nearby items.
- A period that ends exactly on year 0 now renders as a range.

## Tags

- New Tags manager (sidebar button): search tags, see how many items use each one, rename inline, or delete a tag (it is removed from every item that used it).

## Edit item window

- Save comes before Cancel; both show their shortcut (Ctrl+S / Esc).
- Closing with unsaved changes — Cancel, Escape or the window's X — asks before discarding.

## Reliability

- Database schema upgrades are versioned. Before upgrading an older database the app takes a backup and verifies it first; those backups are kept alongside the regular ones and never pruned.
- Startup, import and statistics-database failures show a copyable error report instead of a bare message box.
- Fixed: duplicating a timeline lost its tag, story/chapter reference and character role data.
